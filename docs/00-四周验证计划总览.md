# 设备软件方向 4 周验证计划 v2（Python / Windows）

这组文档将原来的单篇计划按主题拆开，便于分别阅读背景、验收范围和每周任务。四个周计划中的 Day 1–28 保持原有顺序，每周一个 Markdown 文件。

## 文档导航

- [背景与验证问题](01-背景与验证问题.md)：为什么做这个实验、当前方向判断，以及 4 周真正要回答的问题。
- [验收范围与技术约定](02-验收范围与技术约定.md)：最低验收标准、明确不做的功能、技术栈、Broker/Topic 和里程碑。
- [第 1 周：MQTT 双向闭环](03-第1周-MQTT双向闭环.md)：从单向通信做到 MQTT 控制虚拟设备。
- [第 2 周：FastAPI 接入](04-第2周-FastAPI接入.md)：把浏览器/Swagger、FastAPI、MQTT 和虚拟设备连起来。
- [第 3 周：SQLite 历史与报警](05-第3周-SQLite历史与报警.md)：加入遥测历史、高温报警和命令日志。
- [第 4 周：网页闭环](06-第4周-网页闭环.md)：用极简网页完成状态展示、远程控制和最终 Demo。
- [执行规则与四周后判断](07-执行规则与后续判断.md)：WebSocket、视频使用规则、卡住时的处理方式、投入时间和方向判断。

## 使用方式

1. 先读[背景与验证问题](01-背景与验证问题.md)，确认这不是职业定案，而是低成本验证。
2. 再读[验收范围与技术约定](02-验收范围与技术约定.md)，固定项目边界和通信配置。
3. 按周执行四个周计划；每天以当天的验收条件为准，不用死卡日历。
4. 最后根据[执行规则与四周后判断](07-执行规则与后续判断.md)复盘是否继续向工业 IoT、设备集成、ESP32 或 ROS2 延伸。
