# 第 4 周：网页闭环

## 本周先学什么

本周的重点不是做漂亮页面，而是理解浏览器如何把后端数据显示出来，再把用户操作发回后端：

1. HTML：搭出页面结构和设备信息区域。
2. CSS：控制文字、间距、按钮和状态颜色，让页面能清楚区分 ONLINE、WARNING、ALARM 等状态。
3. JavaScript：读取 DOM、响应按钮事件、发起 HTTP 请求、解析 JSON、定时刷新页面。
4. HTTP API：用 `GET` 查询设备状态，用 `POST` 发送 START / STOP / RESET 命令。
5. 前后端状态同步：网页显示的状态应来自 FastAPI 返回的数据；按钮只是发命令，不能直接假设设备已经成功执行。
6. 轮询与 WebSocket：先用每 2 秒一次的轮询完成闭环，理解 WebSocket 是什么即可，不把它作为本周必做项。

## 核心概念是什么

> 表中未缩进表示根概念；`↳` 表示一级从属；`↳↳` 表示二级从属。这里表达的是学习上的组成/依赖关系，不代表严格的协议继承关系。

| 概念（层级） | 简单理解 | 本项目中的用法 |
| --- | --- | --- |
| HTML | 描述网页结构和内容的标记语言。 | 放置设备编号、温度、RPM、状态和按钮。 |
| CSS | 描述网页外观和布局的样式语言。 | 设置卡片、按钮、间距和状态颜色。 |
| JavaScript | 让网页具备交互和数据处理能力。 | 点击按钮、请求 API、更新页面文本。 |
| ↳ DOM | 浏览器把 HTML 解析成的可操作对象树。 | 用 `querySelector` 等方法找到温度、RPM 和状态元素。 |
| ↳ 事件 | 用户或浏览器触发的动作，例如点击按钮。 | 给 START / STOP / RESET 按钮绑定点击处理函数。 |
| ↳ `fetch()` | JavaScript 发起 HTTP 请求的浏览器 API。 | `GET /devices/001` 查询状态，`POST /devices/001/command` 发命令。 |
| ↳↳ GET / POST | GET 通常用于读取；POST 通常用于提交会改变状态的操作。 | GET 读状态，POST 发送控制命令。 |
| ↳ JSON | 前后端交换结构化数据的文本格式。 | 请求体传 `{ "command": "STOP" }`，响应体传设备状态。 |
| 轮询（Polling） | 按固定时间间隔重复请求接口。 | 每 2 秒请求一次设备状态，简单但不是实时推送。 |
| WebSocket | 浏览器和服务器保持长连接，双方可以主动发送消息。 | 作为后续优化方向；本周用轮询即可。 |

### 本周的数据流

```text
页面加载
    ↓ GET /devices/001
FastAPI 返回 JSON
    ↓
JavaScript 更新 DOM
    ↓ 用户点击 STOP
POST /devices/001/command
    ↓
FastAPI → MQTT → 虚拟设备
    ↓
下一次轮询读到 STOPPED
```

这里有一个重要区别：点击按钮只代表“请求已经发出”，不代表设备已经成功改变状态。页面应以之后从 API 读到的真实状态为准。

### 建议参考

- [菜鸟教程：HTML 教程](https://www.runoob.com/html/html-tutorial.html)：了解标签、页面结构和表单/按钮。
- [菜鸟教程：CSS 教程](https://www.runoob.com/css/css-tutorial.html)：只查选择器、盒模型、颜色、间距和简单布局。
- [菜鸟教程：JavaScript 教程](https://www.runoob.com/js/js-tutorial.html)：只查函数、事件、DOM 和定时器。
- [MDN：使用 Fetch](https://developer.mozilla.org/zh-CN/docs/Web/API/Fetch_API/Using_Fetch)：理解 `fetch()`、Promise、JSON 响应和 `response.ok`。

### 本周学习边界

## Day 27：整理 README

README 只写真实有的功能。

### 项目介绍

> 基于 Python、FastAPI 和 MQTT 的单设备监控与远程控制 Demo。

### 当前功能

```text
MQTT 实时上报
FastAPI 查询真数据
在线 / 离线
远程 START / STOP / RESET
SQLite 历史数据
高温报警
Command Log
简单网页控制
```

### 当前不支持

```text
多设备注册
用户权限
工单流转
WebSocket
Docker
Agent
ROS2
```

如果某项后来做了，再删掉对应条目。
